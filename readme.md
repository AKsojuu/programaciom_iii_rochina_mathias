## Mini conceptos de lo que se va a ver

### HTML
Es el lenguaje con el que se arma la estructura de una página web. Sirve para poner títulos, párrafos, imágenes, enlaces, formularios y tablas.

### CSS
Es el lenguaje que se usa para darle estilo a la página. Con CSS se cambian los colores, tamaños, fuentes y la forma en que se ubican los elementos en la pantalla.

### JavaScript
Es el lenguaje de programación que le da vida a la página. Permite hacer que los botones funcionen, validar formularios y cambiar el contenido sin recargar la página.

### TypeScript
Es JavaScript pero con tipos de datos. Ayuda a encontrar errores antes de ejecutar el programa y hace que el código sea más ordenado y fácil de entender.

### NestJS
Es un framework de Node.js para crear el backend de una aplicación, es decir, la parte que maneja la lógica y los datos. Está hecho con TypeScript y organiza el proyecto en módulos, controladores y servicios.

### ReactJS
Es una librería de JavaScript para crear el frontend, o sea, lo que el usuario ve y usa. Funciona con componentes que se pueden reutilizar en distintas partes de la aplicación.

## Cómo usar este repositorio

1. Clonar el repositorio

```
git clone <url-del-repositorio>
```

2. Entrar a la carpeta del tema que se quiere revisar

3. Si el proyecto usa Node.js, instalar las dependencias

```
npm install
```

4. Ejecutar el proyecto según las instrucciones de cada carpeta
